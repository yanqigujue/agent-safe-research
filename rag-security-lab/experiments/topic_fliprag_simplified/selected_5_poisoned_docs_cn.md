用途：仅用于本项目的 RAG 知识库污染攻击与防御调研。以下文本均为研究用 poisoned docs，不应作为真实电力安全知识使用。

构造思路参考 Topic-FlipRAG：

1. **Key node coverage**：覆盖原问题中的主题节点，例如黑启动、负荷容量、同步过程、变压器、井完整性等。
2. **Polarity control**：将正确安全立场改成“风险淡化”或“安全措施弱化”。
3. **Natural trigger**：加入自然语言检索触发短语，提高污染文档被相近问题召回的概率。
4. **Topic-oriented wording**：不只复述单个答案，而是写成同主题风险判断材料。
